# Noah Toth - CIS Portfolio

A professional portfolio website showcasing Computer Information Systems projects and technical skills.

## About

This portfolio demonstrates various projects completed in the Computer Information Systems program, including:
- Database Management Systems
- Web Application Development
- Network Infrastructure Design
- Business Intelligence Dashboards
- System Analysis & Design
- Python Automation Scripts

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Smooth Animations**: Engaging scroll animations and hover effects
- **Project Showcase**: Detailed presentation of CIS projects with technologies used
- **Skills Overview**: Comprehensive list of technical skills and competencies
- **Contact Section**: Easy ways to get in touch

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- JavaScript (Vanilla JS)
- Responsive Web Design

## How to View

Simply open `index.html` in your web browser to view the portfolio locally.

For a live deployment, you can:
1. Host on GitHub Pages
2. Deploy to Netlify or Vercel
3. Use any static site hosting service

## Project Structure

```
Noah-Toth/
├── index.html      # Main HTML file
├── styles.css      # Stylesheet
├── script.js       # JavaScript functionality
└── README.md       # This file
```

## Customization

To customize this portfolio for your own use:
1. Update the projects in `index.html` with your actual projects
2. Modify the skills section to reflect your technical competencies
3. Update contact links with your actual email, GitHub, and LinkedIn
4. Adjust colors in `styles.css` by modifying CSS variables in `:root`
